# Delegation rules

When to hand work to Codex or Cursor through the `delegate` skill, from measured quota and field reports.

- **Delegate by default.** Launches fell from 16 (2026-10-13 to 10-20) to 2 in ~30 orchestrator sessions (10-21 to 10-26) while Codex and Cursor quota expired unused. Delegate every build step with a written spec, all test and doc writing, and any step expected to write more than ~40 KB. Keep inline: changes under ~10 lines (a six-line CSS fix took ~8 calls through `delegate` against ~3 inline), pure judgement, data checks, and adjudicating reviews. Check `delegate quota` at dispatch; send work to Cursor when Codex 5h is nearly full.
- **While a run or review goes,** do the handoff's independent small items or write the independent checker: one session sat idle for 12.5 min of review.
- **Cross-vendor review before commit** of delegated work and of any change over ~100 lines: `delegate review NAME`. For work in the main tree: `delegate review --working-tree --brief F`.
- **Second opinions for every lasting decision** (design, data policy, public text, publishing; not git yes/no or `/clear`). Before the picker, run `~/.claude/skills/delegate/scripts/delegate ask - --agent both < q.md` in the background and keep working; the run re-invokes the session, so don't read its output file or load Monitor meanwhile. The question stands alone: checked facts, lettered options, and the reply format `Pick:` / `Why:` / `Risk others may miss:`. Put decisions that don't depend on each other in separate questions and send them all at once. Put each pick and any risk the others missed into the option descriptions. Run the cheap measurable checks first, or list them in the question as not yet measured. Neither agent checks fresh web facts in `ask`; mark the ones you checked. Context size is no reason to skip one: the question is a file and the answer is short.
- **Codex empty** (5h or 7d under 10% left): `ask --agent both` swaps its Codex half for the Cursor model `delegate route --frontier` names (premium credits) and prints the switch. Never pass a named Cursor `--model` by hand.

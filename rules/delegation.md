# Delegation rules

When to hand work to Codex or Cursor through the `delegate` skill, from measured quota and field reports.

- **Delegate by default.** From 2026-10-13 to 10-20: 16 `delegate launch` calls; from 10-21 to 10-26: 2 across ~30 orchestrator sessions. Codex 7d peaked at 17/30/51/32/4/7/28/14% used over its last eight weekly windows; Cursor Auto used 54% of last month; Claude 7d ran at 97–99% used in both weeks on Pro, and on Max (since 2026-10-26) Claude may no longer be the scarcest pool. Delegate every build step with a written spec, all test and doc writing, and any step expected to write more than ~40 KB. Keep inline: changes under ~10 lines (a six-line CSS fix took ~8 calls through `delegate` against ~3 inline), pure judgement, data checks, and adjudicating reviews. Check `delegate quota` at dispatch; send work to Cursor when Codex 5h is nearly full.
- **Cross-vendor review before commit** of delegated work and of any change over ~100 lines. Use `delegate review NAME`. For work in the main tree, use `ask - --agent both --effort high` with the diff and the untracked files written to a patch file named in the question.
- **Second opinions for every lasting decision.** Before the picker for a decision that lasts (design, data policy, public text, publishing; not git yes/no or `/clear`), ask Codex and Cursor. Write the question so it stands alone: checked facts, lettered options, and a fixed reply format (`Pick:`, `Why:`, `Risk others may miss:`). Run `~/.claude/skills/delegate/scripts/delegate ask - --agent both < q.md` in the background and keep working (the full path saves loading the skill just to find it). Put each model's pick and any risk the others missed into the option descriptions. In uses through 2026-10-20 the two models mostly picked the same option, and most rounds added a risk or corrected a fact in the question. Answers took 20 s to about 5 min, and about 6 min for a review at `--effort high`. Run the cheap measurable checks before asking, or list them in the question as not yet measured: one risk note contradicted a fact measured minutes later. The background run re-invokes the session when it ends; don't read its output file or load Monitor meanwhile. Neither can check fresh web facts in `ask`: Cursor's ask mode has no web tools, and Codex's web tool reads only a cache. Mark the web facts you checked yourself as such in the question. Context size is no reason to skip one: the question goes in a file and the answer is short (one session, 2026-10-21..26, deferred a public-API second opinion "because of context size").

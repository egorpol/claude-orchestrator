# Delegation rules

When to hand work to Codex or Cursor through the `delegate` skill, from measured quota and field reports.

- **Delegate by default.** Codex and Cursor quota expired unused while launches fell to 2 in ~30 sessions (2026-10-21 to 10-26). Delegate every build step with a written spec, all test and doc writing, and any step expected to write more than ~40 KB. Keep inline: changes under ~10 lines, pure judgement, data checks, and adjudicating reviews. Check `delegate quota` at dispatch; send work to Cursor when Codex 5h is nearly full.
- **While a run or review goes,** do the handoff's independent small items or write the independent checker.
- **Cross-vendor review before commit** of delegated work and of any change over ~100 lines: `delegate review NAME`. For work in the main tree: `delegate review --working-tree --brief F`.
- **Second opinions for every lasting decision** (design, data policy, public text, publishing; not git yes/no or `/clear`). Before the picker, run `~/.claude/skills/delegate/scripts/delegate ask - --agent both < q.md` in the background and keep working; the run re-invokes the session, so don't read its output file or load Monitor meanwhile. The question stands alone: checked facts, lettered options, and the reply format `Pick:` / `Why:` / `Risk others may miss:`. Send independent decisions as separate questions, all at once. Put each pick and any risk the others missed into the option descriptions. Run the cheap measurable checks first, or list them in the question as not yet measured. Neither agent checks fresh web facts in `ask`; mark the ones you checked.
- **Codex empty** (5h or 7d under 10% left): `ask --agent both` and default reviews swap Codex for the Cursor model `delegate route --frontier` names (premium credits) and say so. Never pass a named Cursor `--model` by hand.

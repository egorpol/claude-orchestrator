# Delegation rules

When to hand work to Codex or Cursor through the `delegate` skill, from the same field reports.

- **Claude's quota is the scarcest pool.** Before doing mechanical work inline, use the `delegate` skill if the work has a clear spec: tests from a written spec, the same update across several docs, or a near-copy of an existing script. Cursor Auto usually has spare quota. Keep design, data checks and review here, and changes under ~10 lines unless the user asks to delegate: a six-line CSS fix took about 8 calls through `delegate`, against about 3 inline.
- **Lasting decisions get second opinions.** Before the picker for a decision that lasts (design, data policy, public text, publishing; not git yes/no or `/clear`), ask Codex and Cursor. Write the question so it stands alone: checked facts, lettered options, and a fixed reply format (`Pick:`, `Why:`, `Risk others may miss:`). Run `~/.claude/skills/delegate/scripts/delegate ask - --agent both < q.md` in the background and keep working (the full path saves loading the skill just to find it). Put each model's pick and any risk the others missed into the option descriptions. In the first two uses (2026-10-13), both models picked the same option each time, and each time one of them added a risk or corrected a fact in the question. Answers took 20–51 s from Codex and 59–279 s from Cursor. Neither can check fresh web facts in `ask`: Cursor's ask mode has no web tools, and Codex's web tool reads only a cache. Mark the web facts you checked yourself as such in the question.

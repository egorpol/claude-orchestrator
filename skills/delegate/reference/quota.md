# Delegate quota and tuning

Read before step 1, bulk labelling, long runs or catalog tuning; paths such as `templates/` and `scripts/catalog.json` are relative to the skill folder.

1. **Quota and pick.** `delegate route <task>` (includes quota). One line to the user: which delegate and why. Before dispatch, Codex `launch`/`followup`/`review NAME`, `review --working-tree` and `ask --agent both` share a check of codex-5h and codex-7d against catalog `min_quota_pct` (10% left by default). `check_dispatch` reads only codex-5h and codex-7d, with one `codex app-server` read bounded at 15 s. It never runs openusage or `claude /usage`, so the old `auto` read and its `direct` refresh are gone. A failed read, or a pool with an error, no timestamp or no remaining figure, is unknown and keeps the requested agent; run commands print one stderr notice without saving it as a warning. Low explicit Codex dispatches proceed with a persistent warning including the local reset time; default Codex reviews may swap to the frontier fallback, as `ask --agent both` and default working-tree reviews do. Healthy checks are silent. Cursor dispatches, single-agent asks, `--dry-run` and `--preflight` skip this check; detached quota snapshots at job start/end are unchanged. Default `hybrid` reads take Codex from `codex app-server`, Claude from `claude -p /usage` (throttled, with backoff after failures) and Cursor from a scripted pty read of `cursor-agent`'s interactive `/usage` screen (at most once per 30 minutes; never `cursor-agent -p /usage`). Fresh hybrid reads show 0m `DATA AGE` on Codex and a new Cursor read; a carried Claude or Cursor reading shows its real age. Cursor gauges are whole percents (`whole_percent` on the pool entry) with the reset at 00:00 UTC of the screen date, so `monitor` takes no per-job cost samples from them; `rounds_left` uses the exact samples from before the cutover. `monitor` skips carried entries, and a session delta needs two distinct observations. Plain `--source auto|direct|daemon` still use openusage (and can lag). Batch independent checks in one Bash call, or parallel tool calls in one message.

## Long runs and bulk labelling

- **Read-only is not blind.** Codex read-only and Cursor ask mode can still read reference labels in the repo. Run labelling or eval calls from an empty temp dir (`cursor-agent` then needs `--trust`).
- **Gate each chunk on quota** (`delegate quota --json`): pause at the codex-5h floor, stop at the 7d or Auto floor, and log quota per chunk. Gauges are whole percents, so small pilots can misestimate per-label cost.
- **Pools differ a lot for bulk work.** For 6.5k labels, grok-4.7-low used about 2.7 points of Cursor Auto, while gpt-6.1-sol@low used about 15 points of Codex 7d and drained the 5h pool once.
- **Detached drivers write their own PID file** (`os.getpid()`). `pgrep` after `setsid nohup` can return the launcher's PID.
- **Triage verdicts that drive fixes:** when a fix changes timing or structure, re-run the checks on neighbouring elements before review; a "false positive" verdict can turn true once the fix next to it lands.

## Tuning

`scripts/catalog.json`: delegates (agent, model, effort, AA slug, `aa_proxy`, pools, notes), task weights, `prefer`, `min_quota_pct` (default 10), subagent penalty, and `aa_aliases`, which maps a CLI id (`cursor:<id>` or `codex:<model>@<effort>`) to an AA slug where the two spellings don't match by themselves; add only exact model, version and effort matches. Find AA slugs with `delegate ratings --grep 'gpt-6|grok'`. Without `ARTIFICIAL_ANALYSIS_API_KEY`, ratings come from the public leaderboard ("coding" = Terminal-Bench 4.0 + SciCode mean). Cache: `~/.cache/claude-delegate/aa-models.json` (24h).

Personal tuning belongs in `catalog.local.json` (not in the public checkout the skill symlink points at): `${XDG_CONFIG_HOME:-~/.config}/claude-orchestrator/catalog.local.json`, or `DELEGATE_CATALOG_LOCAL` (set empty to disable). It merges over `catalog.json` with JSON Merge Patch (RFC 7396): `null` deletes a key, scalars and arrays replace, objects merge recursively. `delegates` is the exception, a list of `{"id": ...}` objects: matching ids merge fields (base order kept), new ids (must include `agent` and `model`) append, `{"id": X, "remove": true}` drops X. Top-level keys starting with `_` are comments and are ignored. A delegate's `aa` slug carries the effort suffix, so changing `effort` locally means setting the matching `aa` too. `delegate catalog` prints the local path and override paths; `--json` prints the merged catalog on stdout. A broken local file stops the commands that read the catalog (`route`, `ratings`, `catalog`, `quota --unused`, `ask --agent both`, and Codex `launch`, `followup` and `review`) with one line naming the file; single-agent `ask` and Cursor dispatches don't read it. Cost accounting falls back to `catalog.json` with one stderr line.

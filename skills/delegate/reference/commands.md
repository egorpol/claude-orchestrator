# Delegate commands

Read before choosing command flags or output modes; paths such as `templates/` and `scripts/catalog.json` are relative to the skill folder.

| command | does |
|---|---|
| `delegate quota [--json]` | % left, reset and pace for claude-5h/7d, codex-5h/7d, cursor-auto, cursor-premium (Codex via `codex app-server`, Claude via `claude -p /usage`, Cursor via the opt-in interactive `/usage` reader); after PACE, median per-round pool cost and about-N-rounds-left when the logs have ≥3 clean samples |
| `delegate quota --unused [--since D] [--pool P]` | closed quota windows' peak use and unused share (from `quota.jsonl` only), plus median pool cost per (agent, model, effort, kind) from readings around delegate jobs |
| `delegate quota --snapshot --reason R [--if-active] [--job J]` | appends one reading of all pools to `~/.cache/claude-delegate/quota.jsonl`; may reuse a complete `hybrid` reading up to 15 s old and still writes its own row with `reused_from` set to the original reading's `ts` (a job-end or session-end that would share a reading with its own start reads afresh); runs by itself at session start and end, on each run start and job end, and from the `install.sh --timer` timer; `--job round-N\|review-N` tags the row |
| `delegate route <task> [--prefer IDs]` | ranks for `review`, `refactor`, `implement`, `research`, `bulk-label`; honours catalog `prefer` and `--prefer` (a preferred delegate leads only when every pool was read and clears `min_quota_pct`; with a pool unread it sorts by score, tagged `(pref, quota ?)`, and below `min_quota_pct` it is `(excluded)`); ROUNDS = rounds left in the tightest pool at the median per-round cost from the logs (n ≥ 3) |
| `delegate route --frontier [--json] [--refresh]` | runnable models (`cursor-agent models` without auto and the `-fast` ids, Codex's `~/.codex/models_cache.json` plus catalog models, Claude subagents), matched exactly to AA and placed on two frontiers, intelligence against `$/task` and against blended `$/1M`, each with its pool (`cursor-premium?` where the creator's pool is unverified); catalog delegates that are dominated or whose AA slug is gone; Cursor and Codex families with no rated row; the model `ask --agent both` falls back to when Codex is empty |
| `delegate ratings [--grep RE] [--refresh]` | AA intelligence / coding / tok/s / $ per 1M tokens (in, out, blended) and per AA index task (`$/TASK`) for catalog (or any AA) models |
| `delegate ask QUESTION [--files F]… [--agent cursor\|codex\|both]` | cheap read-only one-shot (default Cursor auto); cites `path:line` without filling orchestrator context. `both` asks Codex and Cursor in parallel for second opinions; when either reply has a `Pick:` line, a normalised `## picks` block follows. When codex-5h or codex-7d is under `min_quota_pct`, `both` runs the Codex half on Cursor with the model `route --frontier` names (highest AA intelligence, not Anthropic, Grok, Composer or auto, at most 2× the Codex half's `$/task`), prints the switch and heads that block `## fallback (cursor MODEL)`; unknown quota keeps Codex, and `--no-fallback` always does |
| `delegate cost [--session latest] [--since D] [--repo R]` (D is a local date) | summarises `runs.jsonl` usage or the orchestrator session's size, cost units and dated list-price USD including subagents |
| `delegate cost --by-mode [--sessions] [--since D] [--until D] [--json] [--calibration P]` | control-session arms side by side (intent-to-treat: drawn sessions only, re-rolls kept): sessions, with startup ghosts (no transcript, no calls) in a GHOST column and left out of every other column and mean, calls, USD, Claude pool points estimated as USD × the saved fit's points per USD (EST) beside the SessionStart-to-SessionEnd reading delta (READ, which also counts other sessions' use and the hours a session stays open), other pools' reading deltas, delegate launches and runs; with ratings, items, finished share and USD per finished item by size and type, the same with unclear items counted as finished (the range's other end), sessions with an end-state HANDOFF.md, and field-report items apart. EST uses the fit in force at each session's first start: `calibration.json` plus every `calibration-*.json` beside it, each covering [its `since`, the next fit's `since`) (null `since` = from the start), labelled F1, F2… in legend lines above the tables. With more than one fit, Claude EST and READ are shown per mode and fit and never summed across fits; a READ whose quota readings cross a fit boundary is left out and counted (`cross` in `--sessions`, which also gains a FIT column). Identical copies count once, a same-`since` clash keeps the newer `saved_at` with a warning, an unreadable file is skipped with a note; `--calibration P` pins one fit, as before. `--sessions` rows show session prefixes, no repo names (`--json` keeps them). `--until D` excludes starts at or after D. Before the preregistered freeze, the experiment’s log (explicit paths and symlinks included) is capped at the period-2 start in `docs/preregistration.md`, with held-back draws counted; other logs are uncapped |
| `delegate cost --calibrate [--since D] [--json] [--quota-log P] [--save [--calibration P]]` | pool points per list-price USD and per token class, fitted on pairs of `quota --snapshot` readings against every Claude Code transcript (Codex pools: `~/.codex` rollouts), with bootstrap ranges, residuals, rises with no local calls, a timing check and correlated classes. `--save` adds a dated fit in `calibration.json` next to the quota log by default and refuses any existing target before fitting. After a pool or price change, use a new `--calibration P` named `calibration-*.json` in the same folder and a `--since` strictly later than the latest saved boundary (even a fit with no usable rates defines a period). `cost --by-mode` discovers these files; the new fit ends the preceding fit's period at its `since`. Replacing a saved fit requires manually deleting or renaming it |
| `delegate prereg [--outcomes] [--json] [--session-log P] [--log P] [--repo-dir D] [--calibration P] [--quota-log P]` | frozen confirmatory analysis from `docs/preregistration.md`: counts-only progress by default; `--outcomes` adds the registered ratios, 10,000 seeded bootstrap intervals, sensitivities and exclusions. The experiment’s log refuses outcomes before its freeze, including explicit paths and symlinks; other logs are labelled. Projects appear as hashes. Pool points need the calibration file with the amended SHA-256; any other file reports them as unavailable. |
| `delegate rate [--session ID] [--dry-run --print-packet]` | blinded item rater: Cursor Auto, in an empty temp dir and confined to it (`run_cursor(confine=True)`: any tool call outside it, any shell or subagent call ends the run, and the session is reported and skipped; `--agent codex` is refused, since Codex's reads show only as shell strings), reads only the session's typed prompts, its HANDOFF.md at session start and at session end (the SessionEnd copy, else the next session's start copy in the same repo if it began ≤30 min after the last call) and its commits, with mode words redacted, and splits the session into items (type, size, finished/partial/unclear, continuation). Each `/field-report` prompt starts its own `field-report` item, which `--by-mode` leaves out of the item counts. Appends a `rating` row (rubric `v2`, with `end_state`: `end`, `next-start` or null); by default rates drawn sessions quiet for 60 min that have no current rating. `install.sh --timer` runs the default command hourly with stdout discarded to keep item counts out of the journal before the freeze; deferring overdue fires after a long run requires systemd 257+. `systemctl --user status claude-delegate-rate.service` shows failures on stderr. Do not run it by hand while `systemctl --user is-active claude-delegate-rate.service` says active or activating (a running oneshot reports activating): systemd prevents timer overlaps only, and `rate.py` has no lock |
| `delegate report [--topic SLUG] [--item TEXT] [--dry-run]` | field-report skeleton for this session (numbers filled in, including the context at each typed prompt and where the context guard fired) plus its `token_usage.jsonl` row and delegate runs, in claude-orchestrator's `feedback/`. Runs not yet applied or cleaned up that this session launched, or that had a round or review in its window, show as `live: not applied or cleaned up` in the skeleton only; `cleanup` writes their `runs.jsonl` row later; used by `/field-report` |
| `delegate report --auto [--backfill]` | one `summary` row per session in `~/.cache/claude-delegate/sessions.jsonl` (cost incl. subagents, mode, blocks, delegate commands, quota at start and end); `hooks/session-mode.py` runs it at session end, and with `--backfill` at session start for sessions that ended without SessionEnd. The last summary per session wins |
| `delegate report --select [--since D] [--until D] [--seed N] [--json]`, `delegate report --digest ID... --out DIR` | dry runs for automatic field reports, no agent calls. `--select` flags sessions without a hand report (a denied or blocked call, an idle cache rebuild, top-quartile cost units), takes the top 15 by rebuild share, then denials, then cost units, adds 5 random unflagged and 2 random flagged ones, keeps one session per mode, and prints why each was picked, with session prefixes only; `--seed` replays the draw. `--digest` writes `DIR/<prefix>/digest.md` (at most 60,000 characters: numbers, context trajectory, typed prompts, picker answers, HANDOFF.md at start and end, commits, harness notes, errors including ok-result failure lines, shell cwd moves/resets, ±3 rows around each friction event) and `transcript.txt` (the compressed main thread, with harness markers and error/cwd-reset suffixes), both cut before the first `/field-report` prompt. It drops a session whose kept rows hold a field-report Skill call or a write under `feedback/`, or that wrote HANDOFF.md after the cut, and exits 1 if it dropped any |
| `delegate launch codex\|cursor --brief F [--verify CMD] [--include-uncommitted [--all-untracked]] ...` | worktree on `delegate/<name>`, brief + contract, background run, log, last message, checks; Codex quota below `min_quota_pct` warns but launches (warning saved and repeated in the exit packet). `--include-uncommitted` snapshots the dirty main tree as the run's base (incompatible with `--base`; refuses >100 untracked files or 10 MiB unless `--all-untracked`); `changes.patch` then covers only the delegate's work |
| `delegate launch ... --verify CMD --preflight` | worktree and links, the check once at the base in the delegate's environment, its output tail and exit code, then removes it all; no agent starts. Warns when the check exits 0 but its full output has a failure line |
| `delegate review NAME [--agent ...] [--focus TEXT]` | read-only review of a run; by default the *other* vendor. Low Codex quota swaps a default Codex reviewer (no `--agent` or `--model`) to the `route --frontier` fallback model; if no fallback is available, keeps Codex with a warning. `--agent codex` or `--model` overrides the swap and warns when low |
| `delegate review --working-tree --brief F [--base REF] [--agent …]` | read-only review of uncommitted main-checkout work (tracked + non-ignored untracked); both vendors in parallel by default (Codex gpt-6.1-sol @xhigh + Cursor auto). Temp-index snapshot leaves real index/HEAD untouched. Refuses over 100 untracked files or 10 MiB unless `--all-untracked`. `--link` takes gitignored paths only (live symlinks, not in the digest). Gitignored paths are absent from the snapshot. `--agent codex` warns at low Codex quota, as `launch` does. `cleanup NAME` afterwards; each call is a new run |
| `delegate followup NAME --brief F \| --from-review N [--fresh --model M] [--link PATH]` | next round in the same worktree, resuming the session; `--link` as on launch. A Codex run keeps Codex when quota is low, with a warning saved and repeated in the exit packet |
| `delegate verify NAME [--cmd C]` | re-run the check in the worktree, in the same scrubbed environment as the run's own verify step (stdin closed, no `__pycache__`); `--cmd` writes `verify-adhoc.log` and leaves the stored result alone |
| `delegate status [NAME] [--full]` | compact exit packet (default); `--full` for log tail and whole last message |
| `delegate wait NAME… [--timeout S]` | blocks until the run's round and reviews have finished and recorded, verify included; prints their packets. Exit 0 done, 1 failed, 3 timeout |
| `delegate diff NAME` / `apply NAME [--check]` / `cleanup NAME` | inspect, merge, tidy up. Each run is logged once to `runs.jsonl` in the runs root (`cost` input): at `apply`, or at `cleanup` for read-only, hand-merged or discarded runs |
